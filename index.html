The problem

Search now answers. Brands don't know if they are in the answer.

AI Overviews and AI Mode are live in France since July 2026, and assistants already synthesize and cite sources for millions of queries. The tools that track this are priced for enterprises and built around dashboards, not around fixing pages.

What teams cannot see today

Whether a page is readable by a language model, whether the brand is recognized as an entity, which passages get lifted into an answer, and which competitor is cited instead.

What GeoTools does about it

It turns each question into a repeatable audit with a clear output: the finding, the evidence, and the page-level change that follows. Built by a practitioner who runs these audits for clients every week.

The toolkit

One Mac app. Each audit a single job.

GeoTools packages the audit tools in one native application. API keys are entered once. No terminal, no browser tabs.

Audit workflow

From URL to a prioritized fix list.

Every audit follows the same chain, so results can be compared from one month to the next.

Step 1

Fetch

Retrieve the page, rendered and raw.

Step 2

Perceive

Send text, images and structure to a multimodal model.

Step 3

Measure

Score proximity, entities, freshness and structure.

Step 4

Compare

Set the result against the target query and competitors.

Step 5

Prescribe

Output page-level changes ranked by impact.
